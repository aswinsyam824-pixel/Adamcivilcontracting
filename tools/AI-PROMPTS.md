# AI image prompts — Adam Civil Contracting website

1. Paste each prompt into Gemini, ChatGPT, Midjourney or similar.
2. Save each result in a folder called `generated/` (next to `index.html`) using the **file name** shown, any format (png, jpg, webp).
   For service images make a `generated/services/` folder, e.g. `generated/services/landscaping-pools-2.png`.
3. On a Mac run `./optimize-photos.sh` from the site folder. It resizes, compresses and copies everything into `assets/img/photos/`.

Tips: landscape unless marked portrait. Pick images without a visible watermark. Check hands, tools and equipment look right. AI images are illustrations, so never caption them as Adam’s own projects (SRS SH-NFR-01).
